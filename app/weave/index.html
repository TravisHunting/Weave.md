Export workspace

Save a workspace as one read-only HTML file that anyone can open in a web browser, with no install, server or internet connection. It contains the articles, their links and graph, search and the Weave reader, and cannot be edited or switched to other files.

Diagrams add about 3.4 MB, and only to exports whose articles contain them. Without diagrams, Mermaid blocks show as code.



Web server


Serve workspace folders in a browser while using Weave here. Desktop and browser share file locks and indexing.

    Network
    

    

    Advanced
    Any IP address of this computer, such as one network adapter's address or :: for every IPv6 interface. It replaces the choice above.
    



    The exact address browsers use, such as the HTTPS address of a reverse proxy or tunnel. When set, only that address is accepted. Without it, browsers use this computer's own addresses.
    

    Browsers on your network will sign in over unencrypted HTTP. For access beyond a trusted network, set an HTTPS browser origin and terminate TLS at a reverse proxy or tunnel.
    

    Workspaces to serve
    Your active workspaces are selected by default. Browsers automatically load this selection.
    

    Administrator
    

    At least 12 characters. Leave it empty to keep the current password. Replacing credentials signs out all browser sessions.
    

    Cloudflare Turnstile
    Leave the secret empty to keep it. Turnstile needs internet access at login; local administration remains available.
    

    Background
    

    Background mode keeps Weave in the system tray. Open it again from the tray or by launching Weave. Quit from the tray to stop everything. The server starts only when requested.
    

    Network, workspace and background settings apply the next time the server starts.
    

    Workspaces
      Inactive workspaces
        Workspace refresh
        How Weave notices files changed outside it. These settings belong to each workspace.
        

        Files
        Hiding affects the Files sidebar. Right-click its heading or blank space to show hidden folders. Private runtime folders remain excluded.
        Search options
        

        On: results from every active workspace are ranked together by relevance and labelled with their workspace; the filter beside the results can leave workspaces out. Off: search uses only the workspace in use, which is the workspace of the active tab.
        



        Deep search
        Press Enter in the search box. Deep search uses the workspace in use, because links and connections do not cross workspaces. It gathers source passages, not a generated answer.
        

        Adds articles linked directly to the best matches. This does not affect the results shown while typing.
        



        

        Kanban
        Moving a card writes its board, column and rank to the card's frontmatter. Board columns are kept in the board article. Off: cards can be moved whenever the workspace is writable.
        

        Editing
        A white dot replaces a tab's × when its changes stay unsaved for more than a second, for example while autosave is off, a save is slow or a save failed. With autosave off, unsaved changes stay with their article until you save. Ctrl+Shift+S saves every changed article. Weave asks before closing a tab, a workspace or the window with unsaved changes.
        Underlines are written as <u>…</u> HTML tags, which GitHub, VS Code and Obsidian also show. Off: Ctrl+U does nothing and the Format menu has no Underline; existing <u> tags appear as text.
        Weave's find bar searches the whole open article, sits at the top right of the article pane and steps through matches with Enter and Shift+Enter. The WebView find bar is the browser engine's own: to stay fast, Weave draws only the lines near the screen, so the WebView bar cannot find text further up or down the article. It also appears over the window buttons.
        

        Spellchecking
        The word you are typing is checked once you type a space or punctuation, move the caret away or leave the editor, so half-typed words are not marked. Turn this off to mark misspellings as you type.
        Misspelled words are underlined. Right-click one for suggestions or to ignore it. Link destinations, relationship names, HTML and comments are never checked. The underline's look is set in Appearance › Spelling underline.
        Ignored words
        Ignored words are never marked, in any capitalization. Remove a word with × to check it again.
          

          Storage location
          Weave stores its database and settings in %LOCALAPPDATA%\Weave\.weave by default. Choose a separate folder; Weave will create .weave inside it when you restart. Your Markdown stays in its source folder.
